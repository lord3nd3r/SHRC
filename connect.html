how to connect — SSH or the web tty

# summary
ssh HOST -p 2222
ssh frank@HOST -p 2222
or open the web tty (https)

no password prompt.
your ssh public key is your identity.
# web — any OS

Open the site, click open the web client. You land as Guest######. Web sessions do not keep an SSH key; use /identify each visit if the nick is registered.

# linux

OpenSSH is already installed on current Ubuntu, Debian, Fedora, Arch, and openSUSE. Any terminal is fine (GNOME Terminal, Konsole, kitty, foot).

# only if `ssh` is missing:
sudo apt install -y openssh-client          # Ubuntu/Debian
sudo dnf install -y openssh-clients         # Fedora
sudo pacman -S openssh                      # Arch

ssh HOST -p 2222
ssh frank@HOST -p 2222
ssh-keygen -t ed25519 -C "you@shrc"         # optional, recommended
# macOS

Terminal.app, iTerm2, Ghostty, or Kitty. OpenSSH ships with macOS. No extra package.

ssh HOST -p 2222
ssh frank@HOST -p 2222
ssh-keygen -t ed25519 -C "you@shrc"

Keys go to ~/.ssh/id_ed25519. Storing the key in Keychain is optional.

# windows 11 / windows 10 (1809+)

Use OpenSSH from PowerShell or Windows Terminal. This is the current Microsoft client. You do not need PuTTY.

Check it is installed (Windows 11 usually has it already):

Get-WindowsCapability -Online | Where-Object Name -like 'OpenSSH.Client*'

If State is not Installed, run this in an elevated PowerShell, or Settings → System → Optional features → OpenSSH Client:

Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

Connect (PowerShell, Windows Terminal, or cmd):

ssh HOST -p 2222
ssh frank@HOST -p 2222
ssh-keygen -t ed25519 -C "you@shrc"

Key file: $env:USERPROFILE\.ssh\id_ed25519. PowerShell 5.1 and PowerShell 7 both call the same ssh.exe.

WSL: use the Linux commands from the WSL distro shell.

PuTTY (optional): host HOST, port 2222, type SSH. Convert your key with PuTTYgen if you already live in PuTTY. Prefer OpenSSH otherwise.

# chromeOS

Turn on Linux (Crostini), open the Linux terminal, then the same Linux ssh commands. crosh is more limited; Crostini is the supported path.

# android

Termux (F-Droid or GitHub — the Play build is stale):

pkg install openssh
ssh frank@HOST -p 2222

JuiceSSH and Termius: host HOST, port 2222, protocol SSH.

# iOS / iPadOS

No system ssh. Use Blink Shell, Termius, or Prompt. Host HOST, port 2222, SSH. In Blink: ssh frank@HOST -p 2222.

# first connect

The host key prompt is normal. Type yes. There is no SSH password. If a client asks for a password, it did not send a key and the server fell back to anonymous — that is still fine; you will be Guest######.

After you are in: /nick alice, /join #lounge, /help. /quit or Ctrl+C leaves.
